21ST MONTHSARY WEBSITE — QUICK START

1. Extract this ZIP file.
2. Open the 21st-Monthsary folder in Visual Studio Code.
3. Open index.html in your browser (or use the VS Code Live Server extension).

REPLACE YOUR 10 PHOTOS
Put your own pictures in assets/images and keep these exact filenames:
photo1.jpg through photo10.jpg

The included JPGs are placeholders so the layout works immediately. Replace them with your own photos. If your photo is PNG, either convert it to JPG or update the matching image filename in index.html.

PHOTO ORDER
photo1.jpg  - Main opening photo
photo2.jpg to photo7.jpg - Our Memories gallery
photo8.jpg to photo10.jpg - Our Journey timeline

MUSIC
The original Music.mp3 from your previous project is included as assets/music/music.mp3. Press “Play music” on the website to start it. Browsers generally require a user click before audio can play.

PERSONALIZE THE LETTER
Open message.html and replace the sample paragraphs inside the section marked PERSONALIZE THE LETTER with your own message.

CUSTOMIZATION
Edit colors, fonts, spacing, and layout in style.css. Edit interactions in script.js.

This project uses plain HTML, CSS, and JavaScript. No npm install or build step is needed.
